# Automated-malaria-detection
Deep learning-based malaria cell classification using EfficientNetB0, Grad-CAM explainability, and TensorFlow Lite deployment.
## Features
- Transfer Learning using EfficientNetB0
- Data Augmentation
- Grad-CAM Explainability
- TensorFlow Lite Conversion
- Streamlit Deployment
